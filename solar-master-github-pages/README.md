# Solar Master – Client Dashboard (GitHub Pages)

Upload ALL of these to the ROOT of the repository (not inside a folder):
- index.html
- .nojekyll
- README.md (optional)

Settings > Pages > Deploy from a branch > main > / (root) > Save.
Site: https://<user>.github.io/<repo>/  (press Ctrl+F5 after each update)

Views: Dashboard · Site Wise View · Operations. Every card, chart, legend and table row is clickable.

Upload Data (green button, top right): choose a Portfolio_Analysis-XXth_Round.xlsm/.xlsx.
The workbook is read in the browser only (nothing is sent to a server) and needs the sheets
Summary, Production, Current Analysis, Avail. and MPPT Voltage in the 13th Round layout.
The last uploaded workbook is remembered in that browser; "Restore built-in data" reverts to the 13th Round.
