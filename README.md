# Solar Master – Dashboard with Auto-Calculation Engine

## Deploy (GitHub Pages)
1. Open the repository ROOT page (github.com/<user>/<repo>), not a folder.
2. Add file > Upload files > drag the FILES from this ZIP (index.html, .nojekyll, README.md, docs/) – not the unzipped folder itself.
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Wait for the green tick in Actions, open https://<user>.github.io/<repo>/ and press Ctrl+F5.

## Each round
1. Data Upload > Auto-Analyze Engine > "Download template" (or use docs/Solar_Master_Raw_Data_Template.xlsx).
2. Fill Round Info, Production, Registers, MPPT Voltage (Meta Data / Raw Availability / Round Scope optional).
3. Drop the workbook on "Raw-Data Template" > check dates > Compute > review diagnostics > Add & Project.
   A finished Portfolio_Analysis .xlsm can also be dropped directly.

Meta Data is saved in the browser after first upload. Raw Availability is optional; without it MPPT spikes = 0.
Validation vs 13th Round: docs/13th_Round_Engine_Validation.xlsx (100% inverter-level, 99.9% site-level match).
