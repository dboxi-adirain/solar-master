# Solar Master – Portfolio Dashboard with Auto-Calculation Engine

Live: https://dboxi-adirain.github.io/solar-master/

Views: Dashboard · Site Wise View · Operations · Data Upload

## Data Upload page
1. **Meta Data · Inverter Master** – drop DSD Meta data.xlsx/.csv once. Editable table (filter, + Row, delete, Save, CSV). Saved in the browser and used for every round.
2. **Auto-Analyze Engine** – drop the Raw-Data Template (or Production / Register / MPPT files separately), check dates & name, Compute, review diagnostics, Add & Project. A finished Portfolio_Analysis .xlsm is also accepted and loaded as-is.
3. **Rounds Library** – every round is saved; Project any round to the dashboard or delete it.

Test files in docs/: 13th_Round_Meta.xlsx (Meta master) and 13th_Round_RAW_template_filled.xlsx (13th Round raw data).
