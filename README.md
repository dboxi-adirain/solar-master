# Solar Master – Portfolio Dashboard with Auto-Calculation Engine

Live: https://dboxi-adirain.github.io/solar-master/

Views: Dashboard · Site Wise View · Operations (all cards, charts and rows clickable).

## Each round
1. Upload Data → ⬇ Raw-data template (or docs/Solar_Master_Raw_Data_Template.xlsx).
2. Fill Round Info, Production, Registers, MPPT Voltage (+ Meta Data the first time; Raw Availability / Round Scope optional).
3. Upload Data → drop the file. The engine calculates every KPI and saves it as a round in the Round selector.
A finished Portfolio_Analysis .xlsm can also be dropped (loaded as-is).

Test file: docs/13th_Round_RAW_template_filled.xlsx (13th Round raw data → reproduces the built-in 13th Round).
