Solar Master - GitHub Pages deployment

1. Put index.html and .nojekyll in the root of your GitHub repository.
2. GitHub > Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select your production branch (usually main) and /(root), then Save.
5. The dashboard is self-contained. It does not require npm, React, CDN assets, or a backend.
